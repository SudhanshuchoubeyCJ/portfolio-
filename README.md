# CJ Product Office

A static, responsive portfolio website for Sudhanshu Choubey (CJ).

## Open locally
1. Keep `index.html` and `cj-portrait-original.jpg` in the same folder.
2. Open `index.html` in a modern browser.

No build step or package installation is required.

## First-visit experience
The introduction is the first page. Visitors must complete one of the two interactive product challenges before the portfolio, case studies, AI workflow and contact sections are unlocked. After completing either challenge, the office becomes available and both games can be replayed.

## Notes
- The portrait uses the original supplied photograph with a monochrome CSS treatment; no checkerboard pseudo-transparency is used.
- The orange mascot remains in the bottom-right corner with restrained blinking and no continuous bobbing, shaking or cursor-chasing.
- Project assumptions, informal testing and unverified outcomes are labelled in the case studies.
